### **2. NES BAND-FORCE CORRECTNESS** ⚠️ **MAJOR BUG**

**Ground truth:** PlayAreaTiles is col-major: `col*0x16 + row`, where 0x16 = 22 rows per column. ObjX is in pixels; col = `(ObjX >> 3) & 0x1F`.

**Code line 111–118:**
```lua
local col  = (objx >> 3) & 0x1F
for c = col - 1, col + 1 do
    if c >= 0 and c <= 0x0F then
        for row = 0, 0x15 do
            W(PLAY_AREA_TILES + c * 0x16 + row, 0x24)
        end
    end
end
```

**CRITICAL ISSUES:**

**Issue 1:** Max column bound is **0x0F (15)**, but OW playfield is **16 columns** (0x00..0x0F). The check `c <= 0x0F` is correct, BUT:
- When col=15 and we try `col+1=16`, the write is skipped. This is **intentional and correct** (no columns beyond 15). ✓

**Issue 2:** Row iteration uses `0x15 = 21`, which is **one short of the full 22 rows (0x00..0x15 = 22 total)**. The loop should be `for row = 0, 0x15 do` ✓ (this is correct; Lua loop is inclusive).

**Issue 3:** ⚠️ **HOTSPOT MISMATCH BLOCKER**: Ground truth states:
> "GetCollidableTileStill (Z_07.asm:2110) reads the tile under Link's hotspot from PlayAreaTiles ($6530), col-major (col*0x16+row, 22 rows)."

The probe forces a **3-column band (c-1, c, c+1) across ALL 22 rows (0x00..0x15)**. But:
- InitMode10 reads **one specific tile at Link's hotspot**, not a full band.
- Z_07.asm:2110 hotspot for Link = **ObjY - 8** (documented as "ObjY-8 for Link").
- If ObjY is mid-row (e.g., $90 = 144 px = rows 9–10), the hotspot row = `(ObjY - 8) >> 4` ≈ `(136 >> 4)` ≈ row 8.5.

**The probe ASSUMES the hotspot will land in the forced band by forcing ALL rows.** This works BUT is wasteful and exposes a silent assumption: **if the hotspot row calculation differs, the probe silently misses it.**

**FIX:** The probe should:
1. Read ObjY.
2. Compute hotspot row = `(ObjY - 8) >> 4`.
3. Force ONLY that row in the 3-col band, plus a small margin (±1 row) for safety.

**Verdict:** BLOCKER if the hotspot formula is wrong; if correct, current approach (force all rows) works but is not verified. **Recommend documenting the assumption in a comment and adding a margin check post-capture.**
