**Files modified:**

Decision artifact: `docs/superpowers/decisions/2026-05-XX-chr-budget-lock.md` cited from PR-1 close.

**Acceptance:**

### PR-4 CHR-TRANSIENT-SCENE

**Branch off PR-3 merge.**

**Goal:** OW enemies + UW enemies (per-level swap) + NPCs.

**Files:**
- `RoomRom/src/atlas/level_chr_swap.{c,h}` — DMA state machine.
- States: `IDLE → REQUESTED → BLANK → DMA_SCENE_A → DMA_SCENE_B → READY`. Gameplay halted until READY. Probes assert active bank id.
- Gate: `palette_tick_quiescent()` precondition (avoid DMA queue overflow).
- 4× prebias for transient banks (per Codex P0-2: ObjAnimAttrHeap entries use sub-pal 0..3; raw 1× would render wrong colors).
- gen_atlas.py phases p3e-trans (transient ROM blobs + level lookup) + p3f-state (residency state machine glue).
- Manifest entries for OWSP enemies, UWSP127/358/469 enemies, NPC banks (OW_NPC + CAVE_NPC).
- Hooks: `roomrom_uw_room_render_set_level()`, `roomrom_main_apply_warp_outcome()`, `cave_dispatch.c` cave-entry.

**Acceptance:**
1. Enter L1 → octorok/moblin tiles in VRAM at SCENE_OBJ base.
2. Switch to L2 → tiles change deterministically.
3. Cave entry → cave-dweller bank loaded.
4. ph5.4-9 gates GREEN.
5. State machine probe shows correct sequence on every transition.
